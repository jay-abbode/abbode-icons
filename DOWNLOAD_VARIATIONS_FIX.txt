ABBODE ICONS — DOWNLOAD COUNT FIX (2,854 -> ~783)
=================================================

WHY IT SAID 2,854
  It wasn't grabbing extra folders. For every icon flagged with color variation
  ("Col. Var." = YES), the downloader was also generating a recolored PNG for
  each of the 24 thread-palette colors. So the count was:
     base catalog PNGs (one per icon, your column N)  +  all those recolors.
  The recolors aren't files in column N — the app makes them on the fly.

THE FIX
  Color variations are now OPT-IN. Added an "Include color variations" checkbox
  under File types, defaulting OFF. With it off, PNG = just the catalog PNG from
  column N (one per icon) — which is what you expected. Tick it only when you
  actually want all the thread-color recolors.

  So a PNG-only, all-categories download now shows ~783 files instead of 2,854.

  components/AssetDownloader.tsx
