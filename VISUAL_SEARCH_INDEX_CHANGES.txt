ABBODE ICONS — VISUAL SEARCH INDEX: MENU + SEARCH + SMART BUTTON
===============================================================

WHAT CHANGED (all four of your asks)

1. SCAN ONLY NEW ICONS
   Good news — the build was already incremental under the hood. The server
   tracks which icons already have a description (by PNG file ID), so the first
   run captions everything and every run after only does newly-added icons. No
   change was needed there; the new button just drives it.

2. VISUAL DATA NOW FEEDS THE SEARCH BAR
   The /browse search now folds in each icon's visual description, so a query
   like "stripes", "wood", or "navy" can find an icon by how it LOOKS even when
   its name/tags don't say so. It's weighted BELOW name and tags (your call), so
   a fuzzy visual match never outranks a real name or tag hit — it just surfaces
   things that would otherwise be invisible, ranked underneath.

3. THE BUTTON MOVED TO THE HAMBURGER MENU
   Removed the panel from the Contact Sheet page. It now lives in the menu, at
   the bottom of the "Data & reports" section.

4. SMART LABEL
   - "Scan New Icons" (with a count badge) when unindexed icons exist — tap to run.
   - Greyed-out "Nothing to Scan" (with a ✓) when everything is up to date.
   While running it shows a little progress bar right in the menu; closing the
   menu doesn't stop the scan, and it's safe to reopen to check progress.

   Bonus on the count check: it only runs when you OPEN the menu (not on every
   page load), and it's cached for 15s — so it's even cheaper than the
   "one read per page load" I originally floated.
